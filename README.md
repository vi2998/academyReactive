# 🎓 Academy Reactive

📁 Progetti sviluppati durante l'**Academy Reactive** da **Ottobre 2024 a Febbraio 2025**, utilizzando **Java** e tecnologie correlate.

## 📌 Contenuto

Questa repository contiene esercizi, mini-progetti e casi studio affrontati durante il percorso formativo, con focus su:
- Programmazione orientata agli oggetti (OOP)
- Java backend
- Spring Framework
- Database relazionali e non

## 🛠️ Tecnologie utilizzate

- Java 8
- Java 17
- Spring Boot
- Maven
- PostgreSQL
- MongoDB
- Git
